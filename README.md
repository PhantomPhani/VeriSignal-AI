**VeriSignal** is an advanced research and demo-grade deepfake detection tool that analyzes uploaded video clips using three independent algorithmic detection branches and fuses them into a unified probabilistic authenticity confidence score.

---

## 📌 Features & Key Capabilities

- 🎥 **Multimodal Analysis**: Simultaneously evaluates spatial visual artifacts, physiological rPPG pulse biosignals, and audio-visual lip synchronization.
- ⚡ **Real-time Pipeline**: Accelerated processing via OpenCV, SciPy, and NumPy.
- 📊 **Interactive Dashboard**: Modern dark-mode React UI with interactive signal timelines, frequency spectrum visualizations, and customizable fusion weight tuning.
- 🎛️ **Live Parameter Tuning**: Adjust branch weightings (`Visual Forensics`, `rPPG Biosignals`, `AV-Sync`) directly in the UI to evaluate different detection strategies.
- 🧪 **Sample Generator Script**: Built-in Python script to generate synthetic and authentic test videos for instant evaluation.

## 🔬 Detection Pipeline Branches

1. **Visual Forensics Branch** ([`backend/pipeline/visual_forensics.py`](file:///c:/Users/phani/OneDrive/Attachments/Desktop/VeriSignal/backend/pipeline/visual_forensics.py)):
   - **Frequency-Domain Analysis**: Computes 2D FFT magnitude spectrum to identify high-frequency periodic grid artifacts generated by GANs and Diffusion models.
   - **Boundary Laplacian Variance**: Measures sharpness differentials between facial ROIs and surrounding border regions to catch face-swap blending seams.
   - **Chroma Noise Variance**: Measures YCrCb chromatic variance anomalies.

2. **rPPG Biosignal Branch** ([`backend/pipeline/rppg_biosignal.py`](file:///c:/Users/phani/OneDrive/Attachments/Desktop/VeriSignal/backend/pipeline/rppg_biosignal.py)):
   - **Facial ROI Tracking**: Tracks forehead, left cheek, and right cheek ROIs.
   - **POS Pulse Signal Extraction**: Extracts skin reflectance variations via Plane-Orthogonal-to-Skin (POS) green/color channel signals across frames.
   - **Physiological Processing**: SciPy Butterworth bandpass filtering (0.75 Hz to 3.0 Hz / 45–180 BPM), FFT Heart Rate (BPM) estimation, Signal-to-Noise Ratio (SNR), and inter-ROI phase coherence.

3. **Audio-Visual Sync Branch** ([`backend/pipeline/av_sync.py`](file:///c:/Users/phani/OneDrive/Attachments/Desktop/VeriSignal/backend/pipeline/av_sync.py)):
   - **Viseme Trajectory**: Tracks vertical mouth opening aperture over time.
   - **Phoneme Energy**: Extracts short-time audio energy envelope aligned to video frame timestamps.
   - **Cross-Correlation**: Computes lag/lead offset (in milliseconds) and peak correlation. Handles clips without audio gracefully with an `N/A — no speech detected` state (`reading_confidence = 0.0`).

4. **Fusion Engine** ([`backend/pipeline/fusion.py`](file:///c:/Users/phani/OneDrive/Attachments/Desktop/VeriSignal/backend/pipeline/fusion.py)):
   - Combines branch anomaly scores using a confidence-weighted average:
     $$\text{Synthetic Weight} = \frac{\sum w_i \cdot c_i \cdot s_i}{\sum w_i \cdot c_i + 1e-6}$$
     $$\text{Authenticity Score} = 100 - \text{Synthetic Weight}$$
   - Exposes tunable constants: `DEFAULT_WEIGHTS = {"visual": 0.40, "rppg": 0.35, "av_sync": 0.25}`.

## ⚡ Quick Start & Installation

### Prerequisites
- **Python 3.11+**
- **Node.js 18+** & `npm`

### 1. Setup Virtual Environment & Install Dependencies
```bash
# Clone the repository
git clone https://github.com/PhantomPhani/VeriSignal-AI.git
cd VeriSignal-AI

# Set up Python virtual environment
python -m venv .venv
.venv\Scripts\activate     # On Windows
# source .venv/bin/activate # On Linux/macOS

# Install backend dependencies
pip install -r backend/requirements.txt

# Install frontend dependencies
npm install
```

### 2. Run the Application

**Option A: Single Command Launcher (Recommended)**
```bash
.venv\Scripts\python start_servers.py
```

**Option B: Independent Servers**
- **FastAPI Backend** (Port 8000):
  ```bash
  .venv\Scripts\python -m uvicorn backend.main:app --reload --port 8000
  ```
- **Vite React Frontend** (Port 5173):
  ```bash
  npm run dev
  ```

Open your browser at **`http://localhost:5173`**.

## ⚠️ Disclaimer & Limitations

VeriSignal is built for research, educational, and demonstration purposes.
- **rPPG Sensitivity**: Remote photoplethysmography signals are sensitive to ambient lighting changes, strong compression, and head movements.
- **Probabilistic Output**: Scores represent probabilistic indicators rather than definitive forensic proof.
