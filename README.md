# VeriSignal — Multimodal Deepfake Reality Checker

VeriSignal is a research and demo-grade deepfake detection tool that analyzes uploaded video clips using three independent algorithmic branches and fuses them into a single probabilistic authenticity confidence score.

> **Disclaimer**: VeriSignal is designed as an educational and research tool. Results are **probabilistic indicators** based on computer vision and signal extraction models, not legal or forensic proof of video authenticity.

---

## Technical Architecture

```
                       ┌────────────────────────────────┐
                       │      Uploaded Video Clip       │
                       │   (MP4/MOV, Max 30 Seconds)    │
                       └───────────────┬────────────────┘
                                       │
            ┌──────────────────────────┼──────────────────────────┐
            ▼                          ▼                          ▼
 ┌─────────────────────┐    ┌─────────────────────┐    ┌─────────────────────┐

 │ - 2D FFT/DCT Grid   │    │ - Facial ROI Mesh   │    │ - Mouth Aperture    │

 └──────────┬──────────┘    └──────────┬──────────┘    └──────────┬──────────┘
            │                          │                          │
            └──────────────────────────┼──────────────────────────┘
                                       ▼
                       ┌────────────────────────────────┐
                       │      Confidence-Weighted       │
                       │          Fusion Engine         │
                       └───────────────┬────────────────┘

                       │  Authenticity Score (0-100)    │

```

### Detection Pipeline Branches

1. **Visual Forensics Branch** (`backend/pipeline/visual_forensics.py`):
   - **Frequency-Domain Analysis**: Computes 2D FFT magnitude spectrum to identify high-frequency periodic grid artifacts generated by GANs and Diffusion models.
   - **Boundary Laplacian Variance**: Measures sharpness differentials between facial ROIs and surrounding border regions to catch face-swap blending seams.
   - **Chroma Noise Variance**: Measures YCrCb chromatic variance anomalies.

2. **rPPG Biosignal Branch** (`backend/pipeline/rppg_biosignal.py`):
   - **Facial ROI Tracking**: Tracks forehead, left cheek, and right cheek ROIs.
   - **POS Pulse Signal Extraction**: Extracts skin reflectance variations via Plane-Orthogonal-to-Skin (POS) green/color channel signals across frames.
   - **Physiological Processing**: SciPy Butterworth bandpass filtering (0.75 Hz to 3.0 Hz / 45–180 BPM), FFT Heart Rate (BPM) estimation, Signal-to-Noise Ratio (SNR), and inter-ROI phase coherence.

3. **Audio-Visual Sync Branch** (`backend/pipeline/av_sync.py`):
   - **Viseme Trajectory**: Tracks vertical mouth opening aperture over time.
   - **Phoneme Energy**: Extracts short-time audio energy envelope aligned to video frame timestamps.
   - **Cross-Correlation**: Computes lag/lead offset (in milliseconds) and peak correlation. Handles clips without audio gracefully with an `N/A — no speech detected` state (`reading_confidence = 0.0`).

4. **Fusion Layer** (`backend/pipeline/fusion.py`):
   - Combines branch anomaly scores using a confidence-weighted average:
     $$\text{Synthetic Weight} = \frac{\sum w_i \cdot c_i \cdot s_i}{\sum w_i \cdot c_i + 1e-6}$$
     $$\text{Authenticity Score} = 100 - \text{Synthetic Weight}$$
   - Exposes tunable constants near top of `backend/pipeline/fusion.py`:
     `DEFAULT_WEIGHTS = {"visual": 0.40, "rppg": 0.35, "av_sync": 0.25}`.

## Known Limitations & Fairness Considerations

### rPPG Biosignal Constraints
Remote photoplethysmography (rPPG) relies on detecting minute color variations caused by blood volume pulses under skin tissue:
- **Video Compression & Bitrate**: Heavy video re-encoding (e.g. social media compression, low bitrate) destroys subtle sub-pixel green channel fluctuations.
- **Lighting & Illumination**: Rapidly changing background ambient lighting or flickering screens introduces false noise.
- **Skin Tone & Motion**: rPPG extraction accuracy can vary across different facial skin tones and is sensitive to violent head motion.

> **Mitigation**: To prevent low-quality video from triggering false deepfake flags, each branch outputs a **Reading Confidence** metric ($0.0 - 1.0$). If rPPG reading confidence is low (e.g. $< 0.4$), its weight in the fusion layer is automatically downscaled, preventing bad lighting or compression from unfairly lowering authenticity scores.

## Local Setup & Development

### Prerequisites
- Python 3.11+
- Node.js v18+ & `npm` / `pnpm`

### Installation

1. **Clone & Setup Virtual Environment**:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate  # On Windows
   pip install -r backend/requirements.txt
   ```

2. **Install Frontend Dependencies**:
   ```bash
   npm install
   ```

3. **Generate Sample Test Videos**:
   ```bash
   python scripts/generate_sample_video.py
   ```

### Running Locally

**Option A: Single Command Start (Recommended)**
```bash
.venv\Scripts\python start_servers.py
```

**Option B: Separate Terminal Windows**
1. **Start FastAPI Backend Server** (Port 8000):
   ```bash
   .venv\Scripts\python -m uvicorn backend.main:app --reload --port 8000
   ```

2. **Start Vite React Frontend** (Port 5173):
   ```bash
   npm run dev
   ```

3. Open `http://localhost:5173` in your browser.
